# Agent Capability Matrix

This document is the **single source of truth** for per-agent capabilities in the new agent-first information architecture. It is the input contract for the IA design (`docs/ia-design.md`) and the removal plan (`docs/removal-plan.md`).

**Column vocabulary** (kept identical to the tab labels in AGENTS.md §2):

- **CLI binary** — the actual command invoked to run the agent.
- **Global config** — user-wide config directory / file and its format. Resolved at the user's `$HOME`.
- **Project-local config** — the repo-local config location and format.
- **Context Files** — persistent instruction files the agent loads into the prompt.
- **Skills** — folder-based, model-loadable instruction packs (typically `SKILL.md` manifests).
- **Version/Update** — how the agent reports and applies its own version.
- **Hooks** — external commands run at lifecycle events.
- **Rules** — declarative per-agent rules files (distinct from context files).
- **MCP** — native support for the Model Context Protocol.
- **Plugins** — bundled extension packages shipped as one installable artifact.

For each tab, the cell notes the **Global** and **Local (project)** scope, or `—` if the agent does not support that tab at that scope. Anything that could not be confirmed from an authoritative source is marked `SPECULATIVE` with a note.
